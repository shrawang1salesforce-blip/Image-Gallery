# Sunday Light

A small, responsive image gallery made with plain HTML, CSS, and JavaScript.

## Run it

Open `index.html` in a browser. The photographs are loaded from Unsplash, so an internet connection is needed for the images.

## Included

- Responsive CSS Grid layout
- Eight images with alt text
- Outside / Inside filtering
- Click-to-open lightbox with a close button
- Native `<dialog>` element for the image preview
